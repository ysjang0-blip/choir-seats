# 찬양대 자리배치 웹페이지 설계서

작성일: 2026-08-06

## 목적

매주 소프라노/알토/테너/베이스 인원이 달라지는 교회 찬양대의 자리 지정을 자동화한다.
파트별 인원수 4개만 입력하면 좌석 배치도가 그림으로 나오는 웹페이지를 만든다.

## 사용자와 사용 환경

- 사용자: 찬양대 자리지정 담당자 (개발 지식 없음)
- 주 사용 기기: 휴대폰 (배치도를 카톡 등으로 이미지 공유)
- 배포: 무료 정적 호스팅(Netlify)에 올려 인터넷 주소로 접속

## 좌석 구조 (고정)

- **왼쪽 블록**: 긴 의자 5줄, 각 줄 최대 12명 (총 60석)
  - 소프라노: 각 줄의 왼쪽부터 채움
  - 알토: 각 줄의 오른쪽부터 채움
- **오른쪽 블록**: 긴 의자 4줄, 앞줄부터 5 / 7 / 9 / 11명 (총 32석)
  - 베이스: 각 줄의 왼쪽부터 채움
  - 테너: 각 줄의 오른쪽부터 채움

## 입력

- 소프라노, 알토, 테너, 베이스 인원수 (숫자 4개)
- "배치하기" 버튼

## 배치 규칙

1. **골고루 배치**: 각 파트 인원을 블록의 모든 줄에 최대한 균등하게 나눈다.
   - 왼쪽 블록(줄 크기 동일): 몫을 균등 배분, 나머지는 앞줄부터 1명씩 추가.
     예) 소프라노 22명 → 5·5·4·4·4
   - 오른쪽 블록(줄 크기 상이): 줄 좌석 수(5/7/9/11)에 비례해 배분.
     넓은 뒷줄에 더 많이 앉는다.
2. 한 줄 안에서 두 파트가 좌우 끝에서부터 채워지므로, 남는 자리는 줄 가운데에
   자연스럽게 비고 파트 경계가 시각적으로 구분된다.
3. **정원 초과 처리**: 소프라노+알토 > 60명 또는 테너+베이스 > 32명이면
   배치도 대신 빨간색 경고 문구("좌석이 부족합니다")를 표시한다.
   한 줄 안에서 두 파트 합이 줄 정원을 넘는 경우도 재배분으로 해결하되,
   블록 전체 정원 이내면 반드시 배치 가능하다.

## 출력 (최종 결과물)

- 좌석(긴 의자)을 실제 배열 모양대로 그린 **시각적 배치도**
- **사람 1명 = 작은 원 1개**. 파트별로 구별된 색깔의 원이 좌석 위에 놓인다.
  - 소프라노/알토/테너/베이스 각각 고유 색상 (색약자도 구분 가능한 배색 지향)
- 빈 좌석은 흐린 윤곽(빈 원 또는 빈 자리)으로 표시
- 그림 아래 범례: 파트별 색상과 인원수 (예: ● 소프라노 20명)
- 앞/뒤 방향 표시 (지휘자석/앞쪽 표기)
- **이미지로 저장** 버튼: 배치도를 그림 파일(PNG)로 저장해 카톡 공유 가능
- 휴대폰 화면 우선(반응형) 레이아웃

## 기술 구성

- **파일 하나짜리 HTML** (HTML + CSS + JavaScript, 프레임워크 없음)
  - 서버·데이터베이스 없음. 모든 계산은 접속한 기기 안에서 실행
  - 배치도는 SVG로 그림 (확대해도 선명, 이미지 변환 용이)
  - 이미지 저장: SVG → Canvas → PNG 변환 (외부 라이브러리 없이 브라우저 기본 기능)
- 배포: Netlify Drop (파일 끌어다 놓기) → `https://○○○.netlify.app` 주소 발급
- 유지비 0원

## 구성 요소

1. **배치 계산 로직** (`assignSeats` 함수): 인원수 4개 → 줄별 파트 인원 배열
   - 화면과 분리된 순수 계산 함수로 작성해 단독 테스트 가능하게 한다
2. **배치도 그리기** (`renderChart` 함수): 계산 결과 → SVG 그림
3. **입력 화면**: 숫자 입력 4칸 + 배치하기 버튼 + 오류 안내
4. **이미지 저장**: SVG를 PNG로 변환해 다운로드

## 테스트

- 배치 계산 로직: 대표 사례 검증
  - 균등 분배(나누어떨어짐 / 나머지 있음), 인원 0명 파트, 정원 초과,
    한쪽 파트만 많은 경우, 전원 만석
- 화면: 휴대폰 크기 화면에서 눈으로 확인, 이미지 저장 동작 확인

## 만드는 순서

1. 배치 계산 로직 작성 + 테스트
2. 입력 화면과 SVG 배치도 그리기
3. 이미지 저장 기능
4. Netlify 배포 후 휴대폰에서 최종 확인
